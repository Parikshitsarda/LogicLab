LogicLab is a collection of JavaScript projects focused on programming logic, problem-solving, and pattern generation. In these projects, I have used variables (let), nested for loops, conditional statements (if-else), logical operators (&&, ||), comparison operators (==, >=, <=), string concatenation (+=), arrays, and the includes() method. I have also used console.log() to display output and setTimeout() to control delayed execution. My Name Logic project generates my name using a combination of stars and spaces, while Star Logic generates alphabet letters using specific row and column positions. I have experimented with simplifying conditions by using ranges and arrays, and comparing different approaches to writing the same logic. This repository is where I document my projects, experiments, and progress in JavaScript.
